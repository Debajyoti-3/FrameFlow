# FrameFlow

FrameFlow is a modern full-stack web application built with **Next.js (App Router)**, **Prisma**, and **PostgreSQL**, featuring powerful image and video transformation features with the help of **Cloudinary**.

---

## Features

- User Authentication (Signup & Login)
- Secure JWT-based auth using HttpOnly cookies
- Prisma ORM with PostgreSQL
- Next.js App Router & API Routes
- Secure password hashing with bcrypt
- Production-ready deployment on Vercel
- Serverless & scalable backend

---

## Tech Stack

| Category | Technology |
|--------|-----------|
| Frontend | Next.js(v16), ShadCN, Tailwind |
| Backend | Next.js API Routes |
| Media Upload & Storage | Cloudinary |
| Database | PostgreSQL (NeonDB)|
| ORM | Prisma |
| Auth | JWT, HttpOnly Cookies |
| Security | bcrypt |
| Deployment | Vercel |

## Installation & Setup

### 1️. Clone the repository

```bash
git clone https://github.com/your-username/frameflow.git
cd frameflow
```

---

### 2️. Install dependencies

```bash
npm install
```

---

### 3️. Generate Prisma Client

```bash
npx prisma generate
```

---

### 4️. Run database migrations

```bash
npx prisma migrate dev
```

---

### 5️. Start the development server

```bash
npm run dev
```

Open `http://localhost:3000`
